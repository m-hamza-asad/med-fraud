# User Guide

Sign in with a setup-configured account. Overview separates flagged/no-flag decisions, catalogue scope, and associated value. Upload validates and transactionally commits data. Claims show decision plus coverage; claim detail shows triggered controls, evidence, reason, version, disposition, and disabled counts. Provider and Network screens aggregate tokenized entities; network boundaries come only from explicit `network_id`. Rules displays all 164 controls. Reports exports CSV, Excel, and PDF. Audit is read-only.

`No flag detected` is not a statement that fraud did not occur. `Partial` means an applicable structured control could not run because its input was missing.
