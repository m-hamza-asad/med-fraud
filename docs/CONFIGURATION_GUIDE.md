# Configuration Guide

Every executable rule exposes typed parameters with unit, bounds, provenance, edit authority, and recommendation eligibility. `POLICY_REFERENCE` and `TECHNICAL_INVARIANT` values are locked; utilization data never invents policy or tariff terms. Empirical guidance requires at least 20 mapped observations, uses only claims before the generation date, and discloses method, population, distribution, support, and warnings.

Simulation is non-mutating and reports population, trigger count/rate, robust distribution, and support. Only Admin may save an `ADMIN_EDITABLE` value, and saves are prospective effective-dated versions. Analyst mutation attempts are rejected server-side. Completed runs retain their immutable configuration snapshot and do not change when later versions are created.
