# Testing

Run `.\scripts\test.ps1`. It runs backend tests, Python lint, frontend unit tests, strict TypeScript checking, ESLint, and the production build. Browser E2E and visual screenshots are separate until Playwright browsers are installed.

The parameterized evaluator contract test covers all 149 executable IDs for positive, clean negative, missing input, not-applicable, evidence version, and decimal boundary behavior. It validates the structured-fact adapter, not the absent field-level medical policy definitions.
