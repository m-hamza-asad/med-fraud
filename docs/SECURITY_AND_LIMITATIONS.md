# Security and Limitations

Localhost binding, Argon2 password hashing, HTTP-only same-site cookies, CSRF validation on sensitive writes, generic login errors, extension/size checks, formula-safe CSV export, foreign keys, and audit events form the POC baseline. HTTPS is not used on localhost, so the cookie is not marked Secure. Use tokenized data only.

Authentication rate limiting, complete schema migrations, safe retained-upload quarantine, every canonical entity, and production privacy/compliance controls are not complete. Most importantly, the catalogue does not supply field-level executable contracts for 149 rules. The current boolean structured-fact adapter must not be represented as regulator-approved detection logic.
